# دليل النشر والتشغيل — أكاديمية ناف

كل قناة خارجية (الدفع، البريد، الجوال، الفيديو، إشعارات المتصفح) **مبنية كاملة ومقفلة** حتى تُضاف مفاتيحها ثم تُفعَّل من اللوحة.
النشر لا يحتاج أي تعديل في الشيفرة.

## ١) موارد Cloudflare (مرة واحدة)

```
npx wrangler d1 create naf_academy          # ضع database_id في wrangler.jsonc
npx wrangler kv namespace create AUTH_KV     # ضع id في wrangler.jsonc
npx wrangler r2 bucket create naf-academy-media
```

## ٢) المتغيرات

القيم العامة في `wrangler.jsonc` ← `vars`، والأسرار بـ `npx wrangler secret put <الاسم>`.
**`SITE_URL` يُضبط في بيئة البناء أيضاً** (صفحات تُولَّد مسبقاً تكتب روابطها المطلقة عند البناء).

| المتغير | النوع | لماذا | بدونه |
|---|---|---|---|
| `SITE_URL` | عام | الروابط المطلقة: البريد، الشهادات، الخريطة، صور المشاركة، المشغّل الدوري | تتوقف الرسائل الآلية، وروابط الشهادات نسبية |
| `LEARNER_SECRET` | سرّ (32+) | توقيع جلسات المتدربين وتذاكر الحضور وروابط إلغاء الاشتراك | الموقع لا يعمل في الإنتاج |
| `ADMIN_SECRET` | سرّ (32+) | توقيع جلسة دخول كلمة المرور للوحة | — |
| `ADMIN_PASSWORD` | سرّ | مخرج طوارئ للوحة إن لم يُفعَّل الدخول الموحّد | لا دخول بكلمة مرور |
| `STAFF_AUTH` | عام | `naf-auth` لتفعيل الدخول الموحّد لفريق ناف | دخول كلمة المرور |
| `AUTH_ISSUER` · `PLATFORM_ID` | عام | عنوان مركز naf-id ومعرّف المنصة | اللوحة تعرض رسالة إعداد (503) |
| `CRON_SECRET` | سرّ (24+) | يحمي `/api/cron/notify` (المشغّل الدوري كل 5 دقائق) | لا رسائل آلية |
| `MOYASAR_PUBLISHABLE_KEY` · `MOYASAR_SECRET_KEY` · `MOYASAR_WEBHOOK_SECRET` | أسرار | الدفع الإلكتروني | التسجيل المدفوع «يُفتح قريباً» ونموذج اهتمام |
| `RESEND_API_KEY` · `MAIL_FROM` | سرّ · عام | البريد (رموز الدخول، الرسائل الآلية) | قناة البريد مقفلة |
| `TAQNYAT_API_KEY` · `SMS_SENDER` | سرّ · عام | الرسائل النصية | قناة الجوال مقفلة |
| `CF_ACCOUNT_ID` · `CF_STREAM_TOKEN` · `CF_STREAM_CUSTOMER` | أسرار | فيديو الدروس على Cloudflare Stream بروابط موقّعة | يعمل الفيديو برابط مباشر فقط |
| `RESEND_WEBHOOK_SECRET` | سرّ | أحداث البريد من Resend على `/api/mail/webhook` (التسليم، الفتح، النقر، الارتداد، الشكوى) — فعّل تتبّع الفتح والنقر من إعدادات النطاق في Resend | لا تتبّع ولا كتم تلقائي |
| `ZOOM_WEBHOOK_SECRET` | سرّ | إشعارات Zoom (حدث Recording Completed على `/api/zoom/webhook`) — تُلحق تسجيلات الجلسات تلقائياً بعد تفعيلها من «الجلسات والحضور»، وتحتاج Stream لنسخ الملف | الإلحاق يدوي |
| `VAPID_PUBLIC_KEY` · `VAPID_SUBJECT` · `VAPID_PRIVATE_KEY` | عام · عام · سرّ | إشعارات المتصفح — ولّدها بـ `node scripts/vapid.mjs` | قناة المتصفح مقفلة |

> `PAYMENTS_GATEWAY=mock` بوابة تجريبية للتطوير فقط، وممنوعة في الإنتاج برمجياً.

## ٣) النشر

```
npm run db:migrate:remote      # الترحيلات (0000 … 0008)
npm run db:seed:remote         # المحتوى المبدئي وحزمة الهوية — مرة واحدة على قاعدة فارغة
npm run media:r2               # ملفات الوسائط المحلية (ومنها الشعارات) إلى R2 بالمفاتيح نفسها
SITE_URL=https://… npm run cf:deploy
```

**حزمة الهوية:** `src/content/brand-kit` (معتمدة، لا تُعدَّل ملفاتها) يطبّقها `db-setup` محلياً مرة لكل إصدار
(`KIT_VERSION` في `scripts/brand-kit.ts`): ملفاتها كما هي في `.data/media` بمفاتيح ثابتة `brand-*`، وصفوفها في المكتبة،
وإعداد «الهوية والشعارات». فينقلها `db:seed:remote` إلى D1 و`media:r2` إلى R2 دون أي رفع يدوي
(`npm run media:r2 -- brand-` للشعارات وحدها). على قاعدة D1 قائمة لا يستبدل البذر إعداداً محفوظاً (INSERT OR IGNORE)،
فتُختار الشعارات من اللوحة — وهي في المكتبة بعد البذر.

`cf:deploy` يولّد قبل البناء إعداد OpenNext وغلاف الـWorker (`.cf/worker.mjs`) الذي يضيف معالج الجدولة الدورية،
ثم يحذف الإعداد بعده (قواعد المستودع ترفض رفعه).

## ٤) بعد النشر — من اللوحة

1. **الهوية والشعارات:** مضبوطة من حزمة الهوية. للتغيير: ثلاث صيغ (الشعار الكامل، صيغة الشريط، الرمز)، لكلٍّ نسخة للخلفيات الفاتحة وأخرى للداكنة، بصيغة SVG (تتحرك في مواضع الحركة، ويولّد المحرّر توأمها PNG للبريد والشهادة وصور المشاركة) أو PNG شفاف، والأيقونة المربعة 512×512 — تحلّ فوراً في كل الصفحات.
1. **الفريق والصلاحيات:** ادعُ أعضاء ناف بالبريد بأدوارهم (مالك، محتوى، مالية، مدرب، دعم) — ومن يدخل بلا دعوة يظهر «بانتظار التفعيل» حتى تمنحه دوراً.
1. **الصفحات العامة:** وصف الموقع ورؤوس الصفحات، و**الشروط والخصوصية** في «السياسات» (يراجعها مستشارك) — ميسر يطلب صفحة السياسات قبل التفعيل.
2. **قنوات الرسائل:** فعّل البريد ثم الجوال ثم إشعارات المتصفح — كل قناة تُرفض إن لم تكن مفاتيحها مضافة.
3. **إعدادات الدفع:** بيانات المنشأة (الرقم الضريبي والسجل) ثم مفتاح التفعيل.
4. **الرسائل الآلية:** راجع القوالب والتوقيتات، وأرسل تجربة لنفسك.
5. **قوالب الشهادات:** الموقّعون وصور التوقيع، ثم «معاينة PDF».
6. **طلبات المؤسسات:** بريد من يُبلَّغ بالطلبات الجديدة.

## ٥) التحقق بعد أول نشر

- [ ] `/robots.txt` و`/sitemap.xml` بروابط مطلقة على النطاق الحقيقي.
- [ ] صورة مشاركة دورة (`/courses/<slug>/opengraph-image`) تظهر بالعربية سليمة.
- [ ] شراء تجريبي بمفتاح ميسر الاختباري `sk_test_` ← Webhook ← تسجيل وفاتورة.
- [ ] رسالة دخول بالبريد والجوال تصل.
- [ ] شهادة تجريبية: اعتماد ← PDF ← مسح رمز QR بالجوال يفتح صفحة التحقق.
- [ ] إشعار متصفح حقيقي يصل (بعد تفعيل VAPID) من «ملفي ← تنبيهات هذا الجهاز».
- [ ] «طابور الرسائل» يتحرك كل 5 دقائق (المشغّل الدوري يعمل).
- [ ] طلب جماعي تجريبي فوق 20 مقعداً يكتمل بفاتورته (حد D1 للمعاملات)، ويصل المشتري «تأكيد الطلب والفاتورة».
- [ ] `/policies` تعرض الاسترداد والشروط والخصوصية.
